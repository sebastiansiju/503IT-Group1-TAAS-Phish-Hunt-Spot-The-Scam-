## Project Overview

**Phish Hunt: Spot the Scam** is an educational cybersecurity awareness game designed for teenagers aged 14–16. The game helps players identify phishing scams, suspicious messages, and online threats through interactive decision-making scenarios.

Players must determine whether a message is **SAFE** or a **SCAM** before the timer expires. The game aims to improve cybersecurity awareness while providing an engaging and accessible learning experience.

### Target Audience

**14–16 years old**

---

## How to Play

1. Read each email or message carefully.
2. Identify whether the message is **SAFE** or a **SCAM**.
3. Click the correct option before the timer ends.
4. Each question has 10 seconds to answer.
5. Earn 5 points for every correct answer.
6. Incorrect answers display feedback to help learning.
7. Complete all scenarios to receive your final score.

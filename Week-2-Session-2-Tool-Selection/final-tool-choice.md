# Final Tool Selection

## Selected Tool: Visual Studio Code (VS Code)

### Final Decision

After comparing Visual Studio Code and Scratch, we decided to use **Visual Studio Code (VS Code)** as the primary development tool for our cybersecurity awareness game.

### Reasons for Selection

Our project aims to create a realistic phishing simulation for students aged 15–16. To achieve this, we need a tool capable of producing professional web pages and interactive features.

VS Code was chosen because it:

* Supports HTML, CSS, and JavaScript.
* Allows complete control over the appearance and functionality of the website.
* Enables realistic phishing simulations.
* Provides professional debugging and testing tools.
* Supports extensions that improve development efficiency.
* Integrates with GitHub for version control.
* Is widely used in the software development industry.
* Produces a professional user experience suitable for teenagers.

### Why Scratch Was Not Selected

Although Scratch is beginner-friendly and easy to use, it does not meet the requirements of our project.

The main reasons for rejecting Scratch include:

* Limited design and customisation options.
* Inability to create realistic web pages and phishing emails.
* Lack of support for HTML, CSS, and JavaScript.
* Child-focused appearance that does not suit our target audience.
* Limited ability to simulate real-world cybersecurity scenarios.

### Conclusion

Visual Studio Code provides the professional features, flexibility, and web-development capabilities required for our cybersecurity awareness game. While Scratch is an excellent educational programming tool, it does not offer the realism and functionality needed for this project. Therefore, VS Code was selected as the most suitable development tool.

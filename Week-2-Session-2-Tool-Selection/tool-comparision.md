# Tool Selection

## Introduction

Before starting the development of our cybersecurity awareness game, we evaluated different tools that could be used to create the project. The two main tools considered were **Visual Studio Code (VS Code)** and **Scratch**. Each tool has different strengths and weaknesses, so we compared them against the requirements of our project before making a final decision.

---

## Tool 1: Visual Studio Code (VS Code)

### Overview

Visual Studio Code is a professional code editor developed by Microsoft. It supports web development technologies such as HTML, CSS, and JavaScript, making it suitable for creating realistic web-based applications.

### Advantages

* Supports HTML, CSS, and JavaScript.
* Allows complete control over website design and functionality.
* Provides professional debugging and testing tools.
* Supports extensions that improve productivity.
* Creates realistic web interfaces and phishing simulations.
* Integrates with GitHub for version control and collaboration.
* Widely used in the software development industry.
* Suitable for creating applications for teenagers and adults.

### Disadvantages

* Requires programming knowledge.
* More complex to learn than beginner-focused tools.
* Development can take longer due to increased customisation options.

---

## Tool 2: Scratch

### Overview

Scratch is a block-based programming platform designed primarily for teaching programming concepts to beginners and younger students.

### Advantages

* Easy to learn and use.
* Requires little or no prior coding experience.
* Quick to create simple interactive projects.
* Provides a visual drag-and-drop programming environment.

### Disadvantages

* Limited customisation and design options.
* Cannot create realistic phishing emails or web pages.
* Appears too childish for our target audience of 15–16-year-olds.
* Does not support HTML, CSS, or JavaScript development.
* Limited ability to create professional-looking interfaces.
* Not suitable for realistic cybersecurity simulations.

---

## Project Requirements

Our project requires:

* A realistic phishing simulation.
* Professional web-page design.
* Interactive buttons and links.
* Instant feedback for users.
* A suitable interface for teenagers.
* Support for HTML, CSS, and JavaScript.

After comparing both tools against these requirements, VS Code was found to be the better option.

---

## Final Decision

We selected **Visual Studio Code (VS Code)** because it provides the flexibility, professional features, and web-development capabilities required for our cybersecurity awareness game. While Scratch is excellent for learning basic programming concepts, it does not provide the realism and functionality needed to create an effective phishing simulation for our target audience.

Therefore, VS Code was chosen as the primary development tool for the project.

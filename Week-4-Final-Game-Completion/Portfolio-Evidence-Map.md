# 4. How to Verify the Game Works

To verify the functionality of the game:

1. Open `final-prototype/index.html` in a web browser.
2. Click the “Start Fishing!” button.
3. Play through a full game session.
4. Verify the following systems:

   * Timer changes based on difficulty level
   * Educational feedback appears after each answer
   * Streak system updates correctly
   * Accuracy percentage is displayed at the end
   * Leaderboard saves scores properly
   * Keyboard and mobile controls function correctly

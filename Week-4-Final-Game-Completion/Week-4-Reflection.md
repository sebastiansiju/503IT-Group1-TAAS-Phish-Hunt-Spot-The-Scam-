# Week 4 Reflection — Phish Hunt Final

## Project Information

**Project:** Phish Hunt — Spot the Scam!
**Written By:** Sebastian Siju, Aakash Poudel, Abiral Senchuri
**Date:** 05/28/2026

---

# 1. Project Goal

The goal of this project was to complete an educational cyber-safety game for teenagers aged 14–16. The game was designed to help players recognise phishing scams, suspicious messages, fake QR codes, and online threats through interactive gameplay.

During Week 4, the team focused on:

* Completing all gameplay features
* Improving accessibility and usability
* Testing and fixing bugs
* Preparing final documentation and presentation materials

---

# 2. What Went Well

Several aspects of the project were completed successfully during Week 4:

* All planned build requirements were completed.
* The game became more engaging after adding difficulty levels, streak systems, and leaderboard functionality.
* QR-code phishing scenarios made the game more realistic and relevant to modern online scams.
* The feedback system improved the educational value of the game by explaining why answers were safe or dangerous.
* Accessibility improvements such as keyboard controls, swipe gestures, and readable text improved the user experience.
* Team communication and task distribution improved as the project progressed.

---

# 3. Challenges Faced

The team faced several technical and organisational challenges during development:

* Balancing the timer system across different difficulty levels.
* Fixing issues where keyboard controls triggered multiple answers.
* Managing and testing the leaderboard functionality.
* Ensuring the game worked consistently across different browsers and devices.
* Completing documentation fairly across all team members within the deadline.
* Managing time effectively while finalising gameplay, testing, and presentation preparation.

---

# 4. How Problems Were Solved

The team used several strategies to overcome project challenges:

* A bug-fix log was maintained to track problems and solutions.
* Frequent testing was carried out during development to identify issues early.
* Team meetings were used to divide responsibilities and monitor progress.
* AI tools such as ChatGPT and Claude AI were used to help explain coding concepts, debugging approaches, and documentation formatting.
* Code changes were tested carefully before final implementation.

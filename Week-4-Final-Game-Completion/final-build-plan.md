# Key Features Included in the Final Game

## Gameplay Features

* 23-scenario question pool
* 20 random scenarios selected each game
* Fisher–Yates shuffle system for random gameplay

## Difficulty Levels

* Easy — 12 seconds
* Medium — 10 seconds
* Hard — 8 seconds
* Expert — 6 seconds

## Educational Features

* QR-code phishing scam challenges
* Scam explanation feedback system
* Safe-message explanation system

## Reward and Progression Features

* Streak tracking system
* “On Fire” visual effect for high streaks
* Accuracy percentage tracking
* Best streak records
* Top-10 leaderboard system

## Accessibility Features

* Keyboard support
* Mobile swipe controls
* Readable fonts
* Strong colour contrast
* Teen-friendly wording and instructions
